# 公開とライブ運営のスキル

## 公開前チェックリスト（2026年の要件）
- [ ] **成熟度アンケートに回答する。** 未回答のゲームはプレイ不可。ラベルが無いと Moderate 扱いになる。
  - Minimal / Mild：Roblox Kids（5〜8歳）とSelect（9〜15歳）に届く。
  - Restricted：年齢確認済みの18歳以上のみ。一度付けると戻せない。
- [ ] **16歳未満に届けたい場合の公開要件を満たす。** ID認証、2FA、Roblox Plus 加入（または1,000R$を預ける。条件を満たせば返金）、評価プロセス。日本からでも早めに済ませておく。
- [ ] **有料ランダムアイテム：** 確率表のUIを用意する。luck込みの確率を表示する。PolicyService で販売を制限する（テンプレートで実装済み）。
- [ ] **価格表示は `GetProductInfo` で取得する。** 地域別価格（Managed Pricing）をオンにする。
- [ ] **虚偽の希少性表示をしない。** 外部広告やインフルエンサー案件は、2026-05-04以降は登録とラベル付けが必須。
- [ ] **Rights Manager に登録し、制作記録（git履歴）を残す。**
- [ ] **データの安全性：** BindToClose、セッションロック、ProcessReceipt の冪等性を確認する。Studio で API Services を有効にして実際に保存されるか確かめる。
- [ ] **英語のタイトルと説明文を書く。** 日本語は自動翻訳＋手動で調整する（Localization Table）。
- [ ] **サムネイルは 1920×1080 を5枚作る。** パーソナライズをオンにし、頻繁に作り直さない。
- [ ] **アイコンは 512×512 にする。**
- [ ] **モバイルで確認する。** ボタンの大きさ、文字の読みやすさ、FPS。

## サムネイルとアイコン
- 実際のゲーム画面を基にする。誇大な絵はクリック後の初回離脱率を悪化させ、2026年以降は損になる。
- 構図：主役1体を大きく、ルールが一目で分かる瞬間（盗む・逃げる・レアの光）、文字は3語以内（英語）。
- 実在の人物や他社IPは使わない。AI画像（GPT Image / Nano Banana / Ideogram など）は有料プランで商用権のあるものを使う。
- 5枚は「キャラ主役／状況主役／レア主役／友人と遊ぶ様子／数字インフレ」のように仮説を分けて作る。

## 広告テスト（少額）
- Ads Manager は最低10クレジット（1クレジット＝263R$。1日5クレジット×2日）。入札は CPP / CPM / CPV15。
- 目的はサムネとコンセプトの検証。広告経由のユーザーは推薦（RFY）の評価に入らない。
- 判断の閾値は `roblox-game-concept` スキルの「続けるか撤退するかの判断」表を使う。

## 見るべきKPI（Creator Hub > Analytics）
1. **Acquisition > Home Recommendations：** 表示数、PTR（表示から実際に遊ばれる率）
2. **初回プレイの離脱率、New User First Session Retention（5分後の残存率）：** 毎週見る
3. **D1 / D7 / D28、セッション長：** 中央値は D1 10.3%、D7 1.6%、9.8分
4. **課金率、ARPPU、課金した日数：** 中央値は約3.8%、0.70ドル
5. **ファネル：** カスタムイベントで、チュートリアルの各ステップや初めての卵などの通過率を計測する

## 週次運営の型（ソロでも燃え尽きない設計）
- **毎週：** 小さな更新を1つ（新アイテム3〜5個、バランス調整、バグ修正）。報酬コードを1つ。
- **毎週土曜の同時刻：** イベント（admin abuse型）を30〜90分。天候やブースト、ショップの即時再入荷、限定卵で同時接続のピークを作る。
- **毎月：** 大型更新を1つ（新エリア、新しい仕組み、季節イベント）。
- **在庫の入れ替え：** ショップを5分ごとに入れ替える（例）。即時再入荷はRobuxで買えるDev Productにする。
- AIで量産するもの：新アイテムの定義（GameConfig）、bpyの spec、パッチノート（英語・日本語）、Discord告知文、コード。
- 更新のたびに `games/<slug>/CHANGELOG.md` とKPIの前後比較を残す。

## コミュニティ
- Discord を中心にする（告知、バグ報告、トレード）。Roblox Communities（旧Groups）の Forums も併用する。
- YouTuber / TikTok：切り抜かれやすい瞬間をゲーム側で作る（撮影モード、派手なレア演出）。中堅クリエイターへの依頼は150〜600ドル程度の例がある。
- 外部広告として扱われる案件は、2026年の広告ポリシーに従って登録とラベル付けをする。

## 支援制度
- **Roblox Jumpstart（随時応募）：** 実績がなくても応募でき、UA（ユーザー獲得）を支援してくれる。最初のゲームがD1 15%を超えたら応募する。
